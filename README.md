# 🐍 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer subscription data to identify
patterns related to customer churn, engagement and revenue.

## 🎯 Objective

The objective is to understand customer behavior and identify
factors associated with customer churn.

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔄 Analysis Process

1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Duplicate Removal
5. Feature Engineering
6. Exploratory Data Analysis
7. Data Visualization
8. Business Insights

## 📊 Analysis

The project analyzes:

- Customer churn
- Customer engagement
- Revenue
- Subscription behavior
- Customer characteristics


## 💡 Key Insights

The analysis identified patterns between customer
engagement, tenure, revenue and churn.
